# 🎓 Smart Campus Management System

A modern **MERN Stack based Smart Campus Management System** designed to digitalize and simplify academic and administrative operations for educational institutions.

---

# 📌 Overview

The **Smart Campus Management System** is a web-based platform that provides a centralized environment for administrators, faculty members, and students.

The application is built using **React.js, Node.js, Express.js and MongoDB** and provides role-oriented functionality for managing college-related information and academic workflows.

---

# 🚀 Features

## 👨‍💼 Administrator Module

- Admin login and dashboard
- Manage student information
- Manage faculty information
- Manage academic data
- Access centralized institutional information
- Monitor and manage system records

## 👨‍🏫 Faculty Module

- Faculty dashboard
- Access academic information
- Manage faculty-related information
- Work with student and academic records

## 👩‍🎓 Student Module

- Student login and dashboard
- View profile information
- Access academic information
- View relevant student records

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Kushal57169/College-ERP-System.git

cd College-ERP-System
```

---

## 2️⃣ Configure MongoDB

Make sure **MongoDB Server** is installed and running locally.

Create a `.env` file inside the `server` directory:

```env
CONNECTION_URL=mongodb://127.0.0.1:27017/collegeERP
PORT=5001
```

> ⚠️ Never upload your `.env` file or database credentials to GitHub.

---

## 3️⃣ Install Dependencies

### Frontend

```bash
cd client
npm install
```

### Backend

Open another terminal and run:

```bash
cd server
npm install
```

---

## 4️⃣ Run the Application

### Start Backend Server

Inside the `server` directory:

```bash
npm start
```

Backend:

```text
http://localhost:5001
```

### Start Frontend

Inside the `client` directory:

```bash
npm start
```

Frontend:

```text
http://localhost:3000
```
